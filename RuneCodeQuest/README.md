# アルカナと忘れられた世界 ～タイピングとコードの大冒険～（試作品）

プログラミングとタイピングを、町を直す物語の中で学ぶ 2D見下ろし型ファンタジーRPGの試作品です。

- **プログラミング**：ゴーレムに命令してこわれた建物を直す（全100ステージ）。順次処理 → くり返し → 条件分岐 → 条件つきくり返し → 変数 → 組み合わせ と、少しずつ難しくなります
- **タイピング**：町の草むらから出てくるアルカナと、タイピングで勝負します
- 星を集めるとランクが上がり、金貨で杖やローブを買うとタイピングの攻撃力・守りが上がります

## 起動方法

1. Unity Hub →「Add（追加）」→「Add project from disk」でこの `RuneCodeQuest` フォルダを選ぶ
2. Unity **6000.3.20f1**（Unity 6.3）で開く（ほかの Unity 6 でもたぶん動きます）
3. 初回は自動で `Assets/RuneCodeQuest/Scenes/Main.unity` が作られて開きます
   - 作られなかったときは、メニュー **RuneCodeQuest > メインシーンを作り直す**
4. **Play ▶** を押す

画像やプレハブは使っていません。ドット絵・町・画面はすべてスクリプトで作るので、素材なしでそのまま動きます。
（どのシーンで Play を押しても、`GameBootstrap` がゲームを自動で作ります）

## スタート画面

- 起動すると、大きな太文字のタイトル（1段目に大きく「アルカナ」、2段目に「と 忘れられた世界」）と「PRESS ENTER」が出る（アルカナが ふわふわ飛んでいる）
- Enter・スペース・クリックで、タイトルのメニュー（はじめから・つづきから）へ

## セーブデータ（最大5こ）

- **はじめから**：保存する場所（データ1〜5）をえらぶ → 使っている場所なら「消して作りますか？」と聞く → セーブデータの名前をきめる（12文字まで・日本語OK）→ キャラクターづくり → ゲームスタート
- **つづきから**：セーブデータの一覧（名前・キャラ・ランク・クリア数・前回の場所）からえらぶ → 「つづきから（オートセーブの所）」「セーブした所から」「キャラクターを作りなおす」「このデータを消す」
- 進み具合・持ち物・図鑑などは、セーブデータごとに別々に記録される。ふりがな・タイピングの言葉・音の設定は、全部のセーブデータで同じ
- 前のバージョンのセーブデータは「データ1」になる
- タイトルでは Esc で1つ前の画面にもどる

## 遊び方の流れ

タイトル（はじめから／つづきから）→ キャラクターづくり → あらすじ（「つぎへ」で1文ずつ）→ 町

1. 噴水のそばの **依頼板** で依頼を受ける（町づくりの依頼・おまけの依頼・アルカナ退治の依頼）
2. クエストの依頼を引き受けると、町の外れの **遺跡の入り口（目的地）** に黄色い矢印の印が出る。草むらを通ってそこまで歩き、入り口を調べると **遺跡のエリア** へ移動（読みこみ画面）
   （画面の外にあるときは、画面のはしに「→ 目的地」が出る。受けられるクエストの依頼は1つずつで、依頼板で「やめる」こともできる）
3. エリアは章ごとに景色が変わり、ステージごとに地図の形がちがう。川の手前のゴーレムを調べてクエスト：ゴーレムに命令を作って「▶ 起動」（スクラッチ / Python）→ 4回までに目標を達成 → 資材がもらえる
   - クエストを終えると、ゴーレムがこわれた橋を直して、向こう岸（大きな宝箱）へ行ける
   - エリアには宝箱（金貨・資材）・薬草（上を歩くとひろう）・看板（エリアのお話）・草むら（アルカナ）もある。下の出口から町へもどる
   - 回復の泉（砂の遺跡はオアシス、雪の遺跡は温泉）で体力が全回復。キラキラ光る地面を調べると金貨・薬草・資材が見つかる（1か所1回）
   - 旅人がプログラミングのクイズを出す。正解すると金貨と薬草（エリアごとに1回）。そのあとも練習の問題を出してくれる（ごほうびなし）
     - **プログラムをえらぶ問題**：正しいプログラム1つ・まちがい2つの、3つのプログラムから えらぶ。ワードブロックの人にはクエストと同じブロックの形で、Python の人には Python のコードで見せる（全42問：6章 × 今の章4問＋応用3問）
     - ワードブロックの人は、答えがいつもブロックの形の問題。Python の人は、コードをえらぶ問題と Python の言葉の問題がまざる
     - 問題の種類は「今の章の問題」「応用問題」「ふりかえり問題（前の章）」の3つ。ステージと答えた回数で順番に変わり、答えるたびに ちがう問題になる
     - 答え合わせでは、正しいプログラムを右に大きく見せて、解説を出す
   - 砂の遺跡（第2章）のサボテンにぶつかると、トゲがささって体力が3へる（少し押しもどされる）
4. 解説（お手本つき）→「もう一度する（問題が少しだけ変わる）」か「町にもどる」
5. その建物の町づくりの依頼を全部終えて資材がそろったら、建物の **工事の看板** を調べて **仕上げクエスト**
6. 仕上げクエストを終えると、資材を使って建物が完成。お店が開いたり、新しい道が通れるようになる
7. 草むらを歩くとアルカナが出てくる → タイピングで勝負して、バグのかけら（資材）と金貨を集める
8. 村の建物を全部直すと、村のシンボル（灯台・大樹など）で次の国への手がかりが見つかる → **馬車の御者** に話して次の国の村へ
9. 6つの村をめぐって、最後は星の国ステラリアの **星の神殿** で守り神オルディナとの勝負 → エンディング

### ストーリークエスト（建物ごとに1つ ＋ 旅立ち、全部で34）

プログラミングではない、お話を進めるクエストです（データは `Town/StoryQuests.cs`）。**建物ごとに1つ** あり、そのストーリークエストを終えると、依頼板で その建物の町づくりの依頼が受けられるようになります（それまでは依頼板に「先に ストーリークエストを進めよう」と出る）。前の建物が直ると次のクエストが始まり、師匠が教えてくれます。左上の「目的」にも出ます。

- **話を聞くクエスト**：頭に「！」が出ている町の人に話しかける。全員に聞くとクリア
- **調べるクエスト**：キラキラ光る印の場所を調べる（画面の外にあるときは、画面のはしに矢印）。出てきたアルカナをたおすとクリア
- ほうび：金貨（30〜200枚）と薬草1こ
- 流れ：ストーリークエスト → 依頼板で その建物の依頼 → 建物が直る → 次のストーリークエスト …。村のシンボルが直ったあとの「旅立ち」のクエストを終えると、次の国へ行ける
- 数：ルーネ村 9（建物8＋旅立ち）、アクアリス 6（建物5＋旅立ち）、シルフィード〜ギアルド 5ずつ（建物4＋旅立ち）、ステラリア 4
- 前のバージョンのセーブで先の村まで進んでいた場合は、ルーネ村からストーリークエストを進めると、また次の村へ行けるようになります

### 風船割り（タイピングの練習）

- 1分のあいだ、風船の言葉を打つ。正しく1文字打つごとに風船がふくらみ、打ち終わると限界までふくらんで割れる。言葉は割った数が増えるほど長くなる
- 結果に「割った風船の合計・正しく打てた数・まちがえた数」が出る
- 一度出た言葉は、そのあと6こ（バトルでは4こ）のあいだ出てこない
- 結果発表は、割った数のカウントアップ → ランクのはんこ（S・A・B・C）→ 素材が1つずつ飛び出す。紙ふぶきと風船が舞い、新記録やキャラクリのほうびも出る（Enter で演出をとばせる）

### 音

音のファイルは使わず、`SoundSynth.cs` でプログラムで作っている（ピコピコしたゲーム音）。風船割り・バトルの画面右上の「♪ 音 ON / OFF」で消せる（設定は保存される）

- BGM：タイトル・町・遺跡のエリア・宿舎・クエスト・バトル・風船割りで、それぞれちがう曲
- 町・エリア・宿舎を歩く音（草むらはガサッ。ほかの音に負けないように大きめ）、会話の文字が出るときのしゃべる音（会話は1文字ずつ出る）
- バトル：打つ音・まちがえた音・言葉を打ち終わった音・こうげきされた音・勝ったときのファンファーレ・負けたときの音
- クエスト：起動の音・ゴーレムが歩く音・クリアのファンファーレ・目標にとどかなかった音
- 風船割り：打つ音・割れる音・結果発表の音
- **素材（何回でも）**：1回で割った数でもらえる。5こ〜 ルーン鉱石（10こ〜は2こ）、15こ〜 風の結晶、25こ〜 星くずの石、35こ〜 虹の宝石
- **装備づくり**：鍛冶屋・防具屋で、素材を使って特別な杖とローブを作れる（風の杖・星の杖・虹の杖・風のローブ・虹のローブ）
- **キャラクリのほうび（1回だけ）**：これまでに割った合計で、50こ 風船のリボン・150こ シェフのぼうし・300こ 金のマント・500こ 虹のローブ・800こ ルーンのかんむり。宿舎の鏡で着がえられる
- 北東：**つり場**（つり人に話しかけると、12秒以内に言葉を打ちきれば魚がつれる。魚は金貨と交換。まれに「金のさかな」は資材もくれる）
- 建物を直すと、がれきが片づいて町の奥（東・北）へ進めるようになります。奥の区画ほどアルカナが強くなります
- 町の人に話しかけると、ヒントや物語が聞けます（師匠は「次に何をすればいいか」を教えてくれる）

### アルカナ図鑑（持ち物の中）

- 持ち物（ポケット・I キー）の右上の「アルカナ図鑑」ボタンで開く。閉じると持ち物にもどる。村ごとのタブ（6つ＋ラスボス）で、1つの村の20体を5列×4行で見る。カードの色で ふつう・旅の道・レア・ぬし が分かる。Q／E でタブを切りかえ
- 出会ったアルカナは絵と名前が出る（まだのものは かげと「？？？」）。たおした回数も記録され、たおすと体力・こうげき・金貨と説明が見られる
- 上に「見つけた ○ / 21」「たおした ○ / 21」が出る。矢印キーかクリックでえらぶと、下にくわしい説明

### メニュー（Esc）

- 町・遺跡・宿舎で Esc キーを押すと開く：セーブする／持ち物・図鑑／地図／ゲームにもどる／ゲーム終了（もう一度 Esc でもどる）
- 「ゲーム終了」は「終了する／やめる」を聞いてから、スタート画面（PRESS ENTER）にもどる。もどる前に今いる場所をオートセーブするので、「つづきから」で同じ場所から始められる
- 持ち物・地図・図鑑が開いているときの Esc は、それを閉じる

### セーブ

- 持ち物・金貨・クリアの記録などは、いつも自動で記録される
- 始める場所は2つ覚えておく：
  - **オートセーブ**：30秒ごと・バトルのあと・遺跡や宿舎に出入りしたとき（右上に「オートセーブしました」と出る）
  - **自分でセーブ**：Esc キーでメニューを開いて「セーブする」（町・遺跡・宿舎どこでも）か、宿舎の記録の本。遺跡の中でセーブすると、その遺跡の入り口から始まる
- タイトルで セーブデータをえらんだあと、「つづきから」はオートセーブの場所から、「セーブした所から」は自分でセーブした場所から始まる（場所と日時が横に出る）

### 星とランク

- クエストの星は、3つの条件で1こずつもらえる：★1つ目 ゴールまでクリアする ／ ★2つ目 1回目の起動でクリアする ／ ★3つ目 命令（ブロック）をお手本の数以下にしてクリアする
  - 条件は、クエストの説明ページと、作業中のグリッドの下に出る（命令の数は「今 ○こ」も出る）。結果では、できた条件に ✓ がつく
  - ステージ一覧から やり直してクリアすると、前より多ければ星が記録される。初めてのときに「通過」（星なし）だったクエストも、クリアすれば星がもらえる（一覧では オレンジ色の「通過」）
- 星3つでランクが1上がります。ランクが上がると最大体力・攻撃力が上がり、タイピングのお題も少しずつ難しくなります
- やり直して、星の数を増やすこともできます（星は一番よい記録が残る）

### タイピングバトル

- 草むらを歩くと、ときどきアルカナが出てきます（町のエリアごとに出てくる敵がちがう）
- ローマ字は、いろいろな打ち方でOK：し（shi・si・ci）、ち（chi・ti）、つ（tsu・tu）、ふ（fu・hu）、じ（ji・zi）、しゃ（sha・sya・sixya）、ちゃ（cha・tya・cya）、しぇ（she・sye）、ふぁ（fa・fwa）、うぃ（wi・whi）、くぁ（qa・kwa）、ゔぁ（va）、っ（kka・tch・xtu・ltu）、ん（n・nn・xn。な行の前の n 1回もOK：konnichiha）。小さい字は x でも l でもOK。どちらにも読める打ち方は、両方を追いかけて あとの文字で決める。言葉の最後の「ん」は nn
- 打ったところは緑色に変わる（かなの言葉・英語は1文字ずつ。漢字の言葉は下の読みが緑になり、漢字だけの段階でも打ったところの読みが出る）。風船割りも同じ
- アルカナは全部で120体（6つの村 × 20体）＋ラスボス。1つの村に ふつう12体・旅の道4体・レア3体・旅の道のぬし1体。先の村ほど強い（表は Battle/ArcanaData.cs。強さは村・種類から自動で決まる）
  - アルカナは、その国（村）の草むら・遺跡にだけ出る。今の町はルーネ村なので、草むらも遺跡も ルーネ村のアルカナ（遺跡では旅の道のアルカナも3回に1回くらい）
  - **凶暴な亜種**：ストーリーが進むと、ほかの国のアルカナの「凶暴な亜種」が、いるはずのない国にも まれにあらわれる。出会ったときに亜種になる確率は 第1章 0% → 第2章 11% … 第6章 35%（ストーリーで出てきた国のアルカナだけ）。強さは **プレイヤーの今の強さ（攻撃力・体力・守り）に合わせる**：「がんばって打てば勝てるかな？」くらい（1秒に1.5文字で 35秒くらい打つと たおせて、体力が3分の1くらい のこる。1秒に1文字だと ぎりぎり勝てる）。ランクの「つよさ+N」は かからない。金貨は多め（体力の半分くらい）。数は BattleData.cs の VariantFightSeconds などで変えられる。絵は元のアルカナを赤っぽくしたもの、図鑑には元のアルカナとして記録される
  - 出やすさ：ふつうのアルカナは前の0.75倍（町は1歩 約7%・遺跡は約9%）。レアは前と同じ出やすさ（町は1歩 0.4%）で、出ると「レアモンスター！」と出る
- 表示された言葉を打つと、1文字ごとに攻撃。1語打ち終わるとボーナス攻撃。敵は一定時間ごとに攻撃してきます
- ランクが10・20・30…になるたびに、草むらのアルカナが少しだけ強くなる（1段階ごとに体力+10%、こうげきは2段階で+1くらい、金貨+10%）。それ以外のランクでは強さは変わらない。強くなった敵は名前の横に「つよさ+1」のように出る（つり・オルディナは変わらない）
- 勝つと金貨。負けても宿舎の前で体力が全回復して再開します（金貨は減りません）
- 体力は歩いたりクエストをクリアしたりしても回復しません。宿舎で休むか、薬草（道具屋・エリアで拾える）を使います
- 言葉の種類：
  - **日本語**（スクラッチを選んだ人向け）：打つ日本語を上に大きく出し、その下にお手本（漢字の読み・ローマ字）を書く。ランクに合わせて ローマ字のお手本がいつも出る → 手が止まったときだけ出る → 漢字 → 文
  - **英語**（Python を選んだ人向け）：命令の単語＋意味 → 単語 → 1行のコード → 意味を見てコードを書く
- 手が止まったり、2回まちがえたりすると、残りのお手本がうっすら出てきます
- 日本語入力（IME）はオフにして、半角英数で打ちます。「ん」は次の文字によって `nn` が必要（例：こんにちは → konnnichiha）

## 100ステージの学習の流れ

| 章 | ステージ | 学ぶこと | 新しく使えるもの |

| 第1章 順次処理 | 1〜12 | 命令を順番にならべる | 1〜 すすむ・まほう、3〜 つかう、5〜 ひろう、7〜 左を向く・右を向く |
| 第2章 くり返し | 13〜24 | 同じ動きをまとめる（命令の数に上限あり） | ○回くり返す（21〜 入れ子） |
| 第3章 条件分岐 | 25〜42 | じゃまものや曲がり角の場所が、もう一度するたびに変わる（決めうちせず「もし」で調べる） | もし〜なら・前にじゃまもの、27〜 足元にアイテム、32〜 でなければ・前がかべ |
| 第4章 〜までくり返す | 43〜60 | 長さがわからない道 | 〜までくり返す（while） |

ステージと問題の形の対応は `LevelFactory.StageTemplates` で決めています（並びかえるとステージの順番が変わる）。
問題は `LevelFactory` がお手本の答えから自動で作り、作った問題がお手本で解けることを確かめています。
テストはどの問題も1つです（作るときは、じゃまものの場所などがちがう地図3つで お手本が解けることを確かめてから、1つ目だけ使う）。解説のあとの「もう一度する」は、同じ考え方で 長さ・じゃまものの場所・配置を少しだけ変えた問題になります。前と まったく同じ地図になる問題は、左右反対の地図にします（右に曲がる所が左に曲がる）。

### クエストのルール

- **エラー**：Python の書き方がまちがっていて読めない（ゴーレムは動かない）
- **条件未達成**：命令は実行できたが、目標にとどかなかった（じゃまものの前で止まった、アイテムが残っている、命令が多すぎる、くり返しが終わらない など）
- **ルール違反**（おまけだけ）：しばりより多くブロックを置いた（例：「すすむ」2こまでなのに3こ）。ゴーレムは動かない。数えるのは置いた数なので、くり返しの中で何回動いてもOK
- どちらも挑戦回数を1回使い、ヒントが出ます。挑戦回数を使い切るとクエスト終了 → 解説。挑戦できる回数は、むずかしい章ほど多い（第1章 4回・第2章 5回・第3章 6回・第4章 7回・第5章 8回・第6章 9回。しばりのある「おまけの依頼」は さらに1回多い）。まちがえて直す「トライ＆エラー」も大事な練習なので、失敗すると「あと○回 ためせるよ」と出る。1回目でクリアすると星が1つ増える（解説を見れば、そのステージは「通過」になって先へ進めます）
- 解き方（スクラッチ ⇔ Python）は編集中いつでも切り替え可。作りかけのプログラムは変換して引きつぎます
  （Python にエラーがあるときは、直してから切り替えます）

### Python の命令

本物の Python の書き方にそろえています。動く命令はタートル（turtle）と同じ名前、調べる命令は Python の教材（Reeborg's World）と同じ形です。

| スクラッチ | Python | メモ |
|---|---|---|
| すすむ | `forward()` | タートルと同じ |
| 左を向く／右を向く | `left(90)` ／ `right(90)` | タートルと同じく角度を書く。ゴーレムは90度ずつ（`left(180)` などはエラー） |
| まほう | `use_magic()` | |
| ひろう | `pick_up()` | |
| つかう | `use_item()` | |
| 前にじゃまもの | `obstacle_in_front()` | |
| 前がかべ | `wall_in_front()` | Reeborg と同じ |
| ゴールに着いた | `at_goal()` | Reeborg と同じ |
| 右が通れる／左が通れる | `right_is_clear()` ／ `left_is_clear()` | Reeborg と同じ形 |
| 足元にアイテム | `object_here()` | Reeborg と同じ |
| n を 看板の数 にする | `n = read_sign()` | |
| 関数を作る（86〜） | `def turn_corner():` | 字下げした行が中身。() の中は空。使う行より上で、字下げなしで作る（スクラッチでは「関数を作る」は自動でいちばん上に置かれる） |
| 関数を使う（86〜） | `turn_corner()` | 関数の中で自分を呼ぶことはできない |

前の名前（`turn_left()` など）を書くと、「名前が変わりました」と新しい書き方を教えてくれます。

### Python 入力の安全性

本物の Python は実行しません。`MiniPython` が許可した書き方（ゴーレムの命令、`for i in range(n):`、
`if` / `elif` / `else`、`while`、変数の代入、`read_sign()`、`pass`、コメント）だけを読み取って、ゲーム内のプログラムに変換します。
`import` / `open` / `exec` などは書いても「使えません」と表示されるだけで、PCには何も起きません。
終わらないくり返しも、動ける回数の上限で止まります。

## ドット絵の仕上げ

- すべての絵は、表示する前に Core/PixelDetail.cs で仕上げる：2倍の細かさにして ななめをなめらかに（Scale2x）・輪郭の左上に光、右下に影・太くなったふちどりの外がわを半透明にして細く見せる・広い面にこまかい質感。地面のタイルは はしを となりと同じ色として扱うので、ならべても つなぎ目に線が出ない
- PixelDetail.Enabled = false にすると、仕上げ前の絵にもどせる

| タイピングのお題を変える・増やす | `BattleData.cs` の言葉のリストと `PickWord` |
| ランクの上がり方・体力・攻撃力の計算 | `PlayerStats.cs` |
| 草むらでの敵の出やすさ | `GameManager.cs` の `UpdateTown()` |
| クエストのエリア名・物語・ゴール・アイテムを変える | `QuestThemes.cs` の `All`（1行が1ステージ） |
| 説明文・ヒント・解説・あらすじを変える | `QuestDatabase.cs` |
| 問題の形（道・数・長さ）を変える | `LevelFactory.cs`（ステージごとにお手本の答えを書いている） |
| 挑戦回数・ステージ数を変える | `QuestDatabase.cs` の `MaxAttemptsFor` / `LevelCount` |
| 命令を増やす | `Program.cs` の `CommandType` と `CommandInfo.All` → `GolemRunner.cs` に動きを追加 |
| 見た目（画像）を差し替える | `SpriteFactory.cs` / `TownArt.cs` / `QuestArt.cs` / `CharacterArt.cs` / `MonsterArt.cs` の Sprite を、用意した画像に置きかえる |

| ふりがなの読みを直す・足す | `Furigana.cs` の `Entries`（`"{漢字\|よみ}"` の形。辞書にない漢字は Play 中に Console に表示される） |
