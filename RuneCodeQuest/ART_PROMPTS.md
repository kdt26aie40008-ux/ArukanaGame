# ドット絵づくり用プロンプト集（ChatGPT 用）

「アルカナと忘れられた世界」の絵を、ChatGPT の画像生成で作るための指示文の一覧です。

---

## 0. 使い方

1. ChatGPT で**新しいチャット**を1つ作り、このチャットで全部の絵を作ります（同じチャットのほうが、絵のふんいきがそろいます）。
2. 最初に「**1. 共通ルール**」を、そのまま貼りつけて送ります。
3. 次に、作りたい絵の指示文を**1つずつ**送ります（1回に1枚）。
4. できた絵は、PNG で保存します。ファイル名は各指示文の **📁 ファイル名** に合わせます。
5. うまくいかないときに送ることば：
   - 背景が白いとき →「背景を透明にして、もう一度」
   - 絵柄がずれてきたとき →「最初の共通ルールを守って、1枚目と同じ絵柄で」
   - 文字が入ったとき →「文字や記号は入れないで」
   - 大きすぎる・小さすぎるとき →「キャラを画像のまん中に、画像の8割くらいの大きさで」

> 画像は `Assets/RuneCodeQuest/Resources/Art/` の下に、フォルダごとに入れます（例：`Art/Arcana/プチバグ.png`）。
> 今は **アルカナ（Art/Arcana/）と、主人公・町の人・ゴーレム・ねこ（Art/Character/）** の画像が使われます。入れていない絵は、今のプログラムの絵のままです。
> 町の人の画像の名前は、ゲームの中の名前と同じにします（例：師匠.png、町長.png）。
> ほかの種類（建物・タイル・武器など）の画像も使えるようにするには、「○○の画像も使えるようにして」と言ってください。

---

## 1. 共通ルール（最初に1回だけ送る）

```
これから、子ども向けのファンタジーRPG「アルカナと忘れられた世界」の
ドット絵（ピクセルアート）を1枚ずつお願いします。全部の絵で、次のルールを守ってください。

【絵柄】
・16ビット時代のRPG風のドット絵。ドットがはっきり見える、レトロゲームの絵柄
・かわいくて親しみやすい（小学生向け）。こわすぎない
・はっきりした暗い色のふちどり、左上から光が当たる陰影
・色数は少なめ（1枚で16〜24色くらい）で、明るくあざやか
・ぼかし、グラデーション、写真のような質感、3DCG風は使わない

【画像】
・正方形の画像（1:1）
・背景は透明（PNG）。地面のかげ・枠・文字・ロゴ・サインは入れない
・描くものは1つだけ。画像のまん中に、画像の8割くらいの大きさ
・ゲームのタイル（地面・かべ・水など）だけは、背景透明にせず、画像いっぱいに描いて、
  上下左右にならべても つなぎ目が自然につながる（シームレス）ようにする

【世界観】
・魔法とルーンコード（魔法のプログラム）がある世界
・「アルカナ」は この世界のふしぎな生き物。人間に体のルーンコードを書きかえられて
  兵器にされ、少しあばれている。でも本当はやさしい生き物
・6つの土地：ルーネ村（のどかな村）、水の国アクアリス、風の国シルフィード、
  砂の国サンドリア、機械の国ギアルド、星の国ステラリア

このルールを覚えたら「OK」とだけ答えてください。
```

## 4. キャラクリ（着せかえの部品）

キャラクリは、部品を重ねて1人のキャラを作っています。部品の**位置と大きさが毎回同じ**でないと ずれてしまうので、少し手間がかかります。

1. まず、もとになる体を作ります。

```
着せかえ用の「もとの体」をお願いします。2〜3頭身の子どもの全身、正面、両手を少しひらいて立つ。
髪・服・帽子はなしで、はだ色の体と、シンプルな白い下着だけ。顔は目と口だけ。
このあと送る部品は、すべて この体と同じ画像サイズ・同じ位置に重なるように描いてください。
```
📁 `Art/CharacterParts/体.png`

2. 部品は、次の文の「○○」を入れかえて送ります。

```
さっきの「もとの体」と同じ画像サイズ・同じ位置に重なる「○○」だけを描いてください。
体は描かず、部品以外は透明。色は、あとでゲームで色をぬれるように、白と灰色だけで描いてください。
```

| 種類 | 📁 フォルダとファイル名 | 「○○」に入れるもの |
|---|---|---|
| かみがた（12） | `Art/CharacterParts/かみ_ショート.png` など | ショート / ロング / ツンツン / おだんご / ポニーテール / ボブ / ベリーショート / ツインテール / アホ毛 / もじゃもじゃ / ななめ前髪 / オールバック の髪型 |
| 目（5） | `Art/CharacterParts/目_ふつう.png` など | ふつう / にっこり / キラキラ / つり目 / ねむそう の目（目の色の部分は灰色で） |
| ふく（9） | `Art/CharacterParts/ふく_ローブ.png` など | ローブ / チュニック / パーカー / よろい / ドレス / マント / オーバーオール / 金のマント / 虹のローブ |
| ぼうし（12） | `Art/CharacterParts/ぼうし_まほうの帽子.png` など | まほうの帽子 / キャップ / リボン / かんむり / ずきん / バンダナ / ねこみみ / つの / 花かざり / 風船のリボン / シェフのぼうし / ルーンのかんむり |
