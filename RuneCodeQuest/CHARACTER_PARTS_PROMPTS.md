# キャラクリ部品づくり用プロンプト集（ChatGPT 用）

キャラクリの部品（髪・目・口・服・ズボン・靴・帽子）を、**体にぴったり合うように**描き直してもらうための指示文です。

---

## 0. しくみ

ChatGPT は「部品だけを、決まった位置にぴったり描く」のが苦手です。
そこで、**体の見本（テンプレート）に、その部品を1つだけ着せた絵**を描いてもらいます。

- できた絵と見本の体をくらべて、ちがう所（＝部品）を Claude が自動で切り出します
- 体のうしろにくる髪は「後ろ髪」、体の前にくる髪は「前髪」として、自動で分けます
- ChatGPT の絵が少しずれても、体の位置で合わせ直します
- 背景は透明ではなく**単色のマゼンタ（#FF00FF）**にしてもらいます（透明にすると、白と灰色の市松模様が描かれてしまうため）

---

## 1. 用意するもの（3枚）

| 画像 | 場所 |
|---|---|
| テンプレート_男の子.png | `RuneCodeQuest/CharacterTemplate/` |
| テンプレート_女の子.png | `RuneCodeQuest/CharacterTemplate/` |
| ドット絵キャラクター着せ替え素材集.png | `image/`（前に作ってもらった素材集） |

## 2. 最初に1回だけ送る「共通ルール」

ChatGPT で新しいチャットを作り、**上の3枚の画像を添付して**、次の文を送ります。
全部の部品を、このチャットで作ってください（同じチャットのほうが、絵柄がそろいます）。

```
これから、子ども向けRPGのキャラクリ用のドット絵を、1枚ずつお願いします。
添付の画像は3枚です。
1枚目：テンプレート_男の子（男の子の体の見本）
2枚目：テンプレート_女の子（女の子の体の見本）
3枚目：着せかえ素材集（髪・服・帽子などの部品の一覧）

【毎回かならず守ること】
・テンプレートの体を、そのまま使う。体の位置・大きさ・ポーズ・顔・はだの色・ふちどりを、
  1ドットも動かさない、変えない
・画像は 1024×1024 の正方形。背景はテンプレートと同じ 単色のマゼンタ（#FF00FF）だけ。
  かげ・グラデーション・模様・市松模様・文字・枠は入れない
・絵柄はテンプレートと同じドット絵（同じドットの大きさ、同じふちどりの太さ、同じ色の数くらい）。
  ぼかし・なめらかな線・写真のような質感は使わない
・こちらが指定した部品「だけ」を足す。ほかの部品（髪・服・帽子など）は勝手に足さない
・部品は、素材集の絵のデザインと色をまねて、テンプレートの体にぴったり合うように描き直す
・マゼンタ（#FF00FF）に近い色は、部品に使わない

このルールを覚えたら「OK」とだけ答えてください。
```

## 3. 部品ごとの指示文

`〇〇` の所を、下の「4. 番号の表」を見て入れかえて送ります。**1回に1枚**です。

### 髪
```
テンプレート_〇〇（男の子 か 女の子）に、素材集の「〇〇の髪」の 〇段目・左から〇番目 の髪型を描いてください。
・髪が頭から自然に生えているように、頭のてっぺん・おでこの上・こめかみの はだが見えないように頭をおおう
・耳は出してよい
・前髪は眉の上まで。目には かからない
・長い髪は、肩やせなかの うしろに流す（体や腕の前には重ねない）
・髪の毛のふちどりと、頭のふちどりが二重にならないように、つなげる
・体・顔・下着は テンプレートのまま。髪以外は描かない
```

### 目（男の子のテンプレートだけで作ります。女の子にも使います）
```
テンプレート_男の子の「目」だけを、素材集の「目」の 〇段目・左から〇番目 の目に変えてください。
・位置と大きさは、今の目と同じ所。左右の目のはなれ方も同じ
・まつげ・ひとみ・光の点も、素材集の目をまねる
・眉・鼻・口・ほっぺ・体は テンプレートのまま
```

### 口（男の子のテンプレートだけで作ります。女の子にも使います）
```
テンプレート_男の子の「口」だけを、素材集の「口」の 〇段目・左から〇番目 の口に変えてください。
・位置は今の口と同じ所。大きさは顔に合うくらい
・目・眉・鼻・ほっぺ・体は テンプレートのまま
```

### 服（上の服・ワンピース）
```
テンプレート_〇〇に、素材集の「〇〇の服」の 〇段目・左から〇番目 の服を着せてください。
・服を体にぴったり合わせる：そでは腕にそって、えりは首に合わせる
・すその長さは、ふつうの服は こしまで、ワンピースやドレスは ひざくらいまで
・服でかくれる体（むね・おなか・かた・下着の上のほう）は見えないようにする
・手は そでから出す
・ズボン・スカート・靴・髪・帽子は描かない
```

### ズボン・スカート
```
テンプレート_〇〇に、素材集の「〇〇（男の子のズボン か 女の子のスカート・ズボン）」の 〇段目・左から〇番目 を はかせてください。
・こしから下に、足の形にそって合わせる
・下着が見えないように、ちゃんとかくす
・上の服・靴・髪・帽子は描かない
```

### 靴
```
テンプレート_〇〇に、素材集の「〇〇の靴」の 〇段目・左から〇番目 の靴を はかせてください。
・足の形と向きに合わせて、足首から下に
・左右の足の両方に
・ほかの部品は描かない
```

### 帽子
```
テンプレート_〇〇に、素材集の「〇〇の帽子」の 〇段目・左から〇番目 の帽子を かぶせてください。
・頭にぴったりのる 大きさと角度で。あとで髪の上にかぶるので、頭のまわりより少しだけ大きめに
・顔（目・口）は かくさない。フードや ねこみみの帽子も、顔は出す
・帽子の中に、別の顔や目を描かない
・髪は描かない（帽子だけ）
```

番号は **左上から右へ、上の段から下の段へ** 数えたものです。
できた絵は、この番号のファイル名で保存します（例：`03.png`）。

| 種類 | 段と数 | 番号 |
|---|---|---|
| 男の子の髪 | 1段目 6こ ／ 2段目 6こ | 1段目＝01〜06、2段目＝07〜12 |
| 女の子の髪 | 1段目 7こ ／ 2段目 7こ | 1段目＝01〜07、2段目＝08〜14 |
| 目 | 1〜3段目 各4こ（左右の目で1こ） | 1段目＝01〜04、2段目＝05〜08、3段目＝09〜12 |

## 5. できた絵の保存先

`RuneCodeQuest/CharacterTemplate/着せた絵/` の下に、次のフォルダを作って保存します。

```
着せた絵/
  男の子/髪/01.png 〜 12.png
  女の子/髪/01.png 〜 14.png
  目/01.png 〜 12.png
  口/01.png 〜 12.png
  男の子/服/01.png 〜 18.png
  女の子/服/01.png 〜 15.png
  男の子/下/01.png 〜 10.png     ← ズボン
  女の子/下/01.png 〜 12.png     ← スカート・ズボン
  男の子/靴/01.png 〜 10.png
  女の子/靴/01.png 〜 13.png
  男の子/帽子/01.png 〜 12.png
  女の子/帽子/01.png 〜 15.png
```

全部で約150枚です。一度に全部でなくて大丈夫です。**作った分だけ**入れてもらえれば、その部品だけ新しい絵に入れかえます（ない部品は今の絵のまま）。

おすすめの順番：**髪 → 服 → 目 → 口 → ズボン・スカート → 靴 → 帽子**（見た目が大きく変わるものから）

保存したら、Claude に「**着せた絵を取りこんで**」と言ってください。

## 6. うまくいかないとき

| こまったこと | 送ることば |
|---|---|
| 体の位置・大きさ・ポーズが変わった | 「体はテンプレートと1ドットも変えないで、もう一度。足したのは〇〇だけにして」 |
| 顔が変わった | 「顔（目・眉・口）はテンプレートのままにして、もう一度」 |
| 背景がマゼンタでない・市松模様になった | 「背景は単色のマゼンタ #FF00FF だけにして、もう一度」 |
| 頼んでいない部品が増えた | 「〇〇以外は描かないで、もう一度」 |
| ぼやけた・絵柄が変わった | 「テンプレートと同じドットの大きさの、くっきりしたドット絵で、もう一度」 |
| 髪から頭のはだが見える | 「頭のてっぺんと横のはだが見えないように、髪で頭をおおって」 |
| 長い髪が体の前にきた | 「長い髪は肩とせなかの うしろに流して、体の前に重ねないで」 |
| 服から下着や体が見える | 「服でかくれる所の体と下着は見えないようにして」 |
