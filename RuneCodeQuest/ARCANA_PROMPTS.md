# 新しいアルカナ 93体の絵づくり（ChatGPT 用）

アルカナは全部で120体（6つの村 × 20体）です。今、画像があるのは28体なので、残りの絵を ChatGPT で作ってもらうための指示文です。
**村ごとに1枚**（4×4のマスに並べた1枚の画像）で頼みます。全部で6枚です。

---

## 1. 最初に1回だけ送る「共通ルール」

ChatGPT で新しいチャットを作り、前に作ってもらった **アルカナの一覧の画像**（image フォルダの「アルカナとキャラクター」）を添付して、次の文を送ります。

```
これから、子ども向けRPG「アルカナと忘れられた世界」のモンスター「アルカナ」のドット絵を、
村ごとに1枚ずつお願いします。添付の画像は、これまでに作ったアルカナです。この絵柄に そろえてください。

【毎回かならず守ること】
・16ビット時代のRPG風のドット絵。はっきりした暗い色のふちどり、左上から光が当たる陰影
・かわいくて親しみやすい（小学生向け）。こわすぎない
・画像は 1024×1024 の正方形。背景は単色のマゼンタ（#FF00FF）だけ（市松模様・グラデーション・かげは入れない）
・画像を たて4マス × よこ4マス の16マスに分けたつもりで、1マスに1体ずつ、マスのまん中に置く
・アルカナどうしは重ねない。マスとマスの間を 広めにあける
・文字・番号・名前・見出し・枠線・マスの線は いっさい入れない
・指定した順番どおりに、左上から右へ、上の段から下の段へ ならべる
・マゼンタ（#FF00FF）に近い色は、アルカナに使わない
・キラキラなどの小さなかざりは、そのアルカナのマスの中だけに描く

このルールを覚えたら「OK」とだけ答えてください。
```

## 3. うまくいかないとき

| こまったこと | 送ることば |
|---|---|
| 文字や番号が入った | 「文字・番号・名前は いっさい入れないで、もう一度」 |
| 背景がマゼンタでない・市松模様 | 「背景は単色のマゼンタ #FF00FF だけにして、もう一度」 |
| アルカナどうしが重なった・くっついた | 「4×4のマスに1体ずつ、間を広くあけて、重ならないように、もう一度」 |
| 順番がちがう・数がちがう | 「指定した順番どおり、左上から右へ {数}体 ならべて、もう一度」 |
| 絵柄がちがう | 「添付のアルカナと同じ絵柄のドット絵で、もう一度」 |
